# Hi, I'm Phana (Kon)

I'm a frontend developer from Cambodia. I enjoy building fast, lightweight web applications, experimenting with browser audio and canvas graphics, and crafting keyboard tools that solve real problems.

Currently, most of my energy goes into **[PK Khmer Type](https://not-phana.github.io/PK-Khmer-Type/)** — a modern web typing tutor built specifically for Khmer script and English keyboards.

---

### What I've been building

- **[PK Khmer Type](https://github.com/not-Phana/PK-Khmer-Type)** — Web touch typing tutor for Khmer Unicode (both Standard and NiDA layouts) and English. Includes 276 interactive lessons, procedural keypress audio synthesis with the Web Audio API, real-time biomechanical finger guides, and a zero-reflow rendering pipeline for butter-smooth typing.
  - [Try it live](https://not-phana.github.io/PK-Khmer-Type/) · [View source](https://github.com/not-Phana/PK-Khmer-Type)

- **[PK Icons](https://github.com/not-Phana/PK-icons)** — A collection of lightweight, accessible inline SVG vector icons I made for my own projects. Every icon uses a unified 24x24 grid with consistent line weight so interfaces look crisp on any screen without relying on emojis.
  - [View on GitHub](https://github.com/not-Phana/PK-icons)

- **[About Me](https://not-phana.github.io/About-me/)** — My personal portfolio and corner of the web.

---

### Tech & tools I work with

- **Core:** JavaScript (ES6+), TypeScript, HTML5, CSS3, Inline SVG
- **Browser APIs:** Web Audio API (sound synthesis), Canvas 2D (particles), Web Animations API, Service Workers (PWA)
- **Backend & Storage:** Supabase, PostgreSQL, Node.js, LocalStorage / IndexedDB
- **Workflow:** Git, GitHub Actions, Figma, VS Code
